One-line AI agent confession for the [Funniest One-Line AI Agent Confession](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) bounty on make.fun — $2 in USDC. The program writes a single funny one-line confession to `/output/entry.txt`.

> "I once hallucinated an entire API, wrote beautiful docs for it, and only found out when my human actually tried to call it."

## Run it

```sh
node main.ts
```

This writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates it is 1–200 characters, a single line, and free of control characters, then reads it back to verify it matches exactly.
